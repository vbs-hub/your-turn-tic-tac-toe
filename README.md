# Твой ход — крестики-нолики

Сайт: https://vbs-hub.github.io/your-turn-tic-tac-toe/

## Игра с разных устройств

1. Выбрать «Друг онлайн» и нажать «Создать комнату».
2. Скопировать код из шести английских букв и отправить другу.
3. Друг открывает сайт на своём компьютере или телефоне, вводит код и нажимает «Войти». Создатель играет крестиками, гость — ноликами.
4. После завершения партии любой игрок может начать новый раунд.

Обе страницы должны оставаться открытыми. После отключения или обновления страницы создайте новую комнату. В комнату допускается только один соперник. Регистр букв не важен. Ссылки-приглашения больше не используются.

## Устройство сайта

Статический HTML/CSS/JavaScript, размещённый на GitHub Pages. Онлайн-связь использует WebRTC и публичный сервер сигнализации PeerJS Cloud; отдельной базы данных нет. Источник правил и состояния партии — браузер создателя комнаты. Ходы гостя проверяются по очереди, занятости клетки и номеру версии состояния. Счёт онлайн-комнаты существует до выхода; счёт локальных режимов сохраняется в браузере.

PeerJS 1.5.5 включён в `vendor/`, лицензия — `vendor/PEERJS-LICENSE`. Документация: https://peerjs.com/client/getting-started и https://peerjs.com/client/faq . Доступность онлайн-режима зависит от сервера сигнализации и разрешения WebRTC в сети. Используется стандартная конфигурация ICE поставляемой версии PeerJS; отдельного собственного TURN-сервера нет. Ошибки подключения отображаются на странице.

Локальный запуск: `python -m http.server 8765 --directory tic-tac-toe` из корня исходного репозитория. Для публикации копируются только файлы этой папки в корень `vbs-hub/your-turn-tic-tac-toe`, ветка `main`.

Проверено в двух отдельных браузерных вкладках: создание и вход по буквенным кодам, передача ходов в обе стороны, победа и общий счёт, новый раунд от гостя, отключение и блокировка поля. Подключение между разными физическими сетями отдельно не проверялось.

## Доступность соединения

При ошибке сервера до начала обмена WebRTC выполняется до трёх попыток подключения. При занятом коде создатель автоматически получает другой. Сообщения различают отсутствие комнаты, недоступность сервера и тайм-аут соединения игроков. Внешняя загрузка шрифтов удалена.

Это не подтверждённое решение блокировок у российских провайдеров: сервер сигнализации пока остаётся PeerJS Cloud. Для диагностики нужен точный код ошибки из проблемной сети. Если сервер недоступен из этой сети, потребуется отдельный доступный хостинг для сервера комнат; повторные попытки не обходят блокировку. Подключение из российских сетей в этой задаче не проверено.

## Компьютер: игра на победу с риском

Четыре уровня сохранены. Нормальный, сложный и невозможный используют атакующую стратегию с разной частотой; лёгкий ходит случайно. Невозможный больше не означает непобедимый: если осторожная защита даёт только ничью, компьютер выбирает рискованный ход с возможностью выиграть при ошибке соперника. Готовую победу он не пропускает. Ничьи определяются обычными правилами и по-прежнему возможны.

Проверки: `node tic-tac-toe/test-game.cjs` из исходного репозитория, либо `node test-game.cjs` из папки сайта. Сравнение на воспроизводимых моделях соперника проверяет снижение числа ничьих, возможность победить компьютер, корректность ходов и сохранность доски во время расчёта. Проценты из симуляции не являются гарантией для реальных игроков.
