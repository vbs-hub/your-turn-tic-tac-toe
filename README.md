# Твой ход — крестики-нолики

Сайт: https://vbs-hub.github.io/your-turn-tic-tac-toe/

## Игра с разных устройств

1. Выбрать «Друг онлайн» и нажать «Создать комнату».
2. Скопировать приглашение и отправить другу.
3. Друг открывает ссылку на своём компьютере или телефоне. Создатель играет крестиками, гость — ноликами.
4. После завершения партии любой игрок может начать новый раунд.

Обе страницы должны оставаться открытыми. После отключения или обновления страницы создайте новую комнату. В комнату допускается только один соперник. Можно также вставить ссылку или код в поле входа.

## Устройство сайта

Статический HTML/CSS/JavaScript, размещённый на GitHub Pages. Онлайн-связь использует WebRTC и публичный сервер сигнализации PeerJS Cloud; отдельной базы данных нет. Источник правил и состояния партии — браузер создателя комнаты. Ходы гостя проверяются по очереди, занятости клетки и номеру версии состояния. Счёт онлайн-комнаты существует до выхода; счёт локальных режимов сохраняется в браузере.

PeerJS 1.5.5 включён в `vendor/`, лицензия — `vendor/PEERJS-LICENSE`. Документация: https://peerjs.com/client/getting-started и https://peerjs.com/client/faq . Доступность онлайн-режима зависит от сервера сигнализации и разрешения WebRTC в сети. Для некоторых NAT/корпоративных сетей потребуется собственный TURN-сервер; он в этой версии не настроен. Ошибки подключения отображаются на странице.

Локальный запуск: `python -m http.server 8765 --directory tic-tac-toe` из корня исходного репозитория. Для публикации копируются только файлы этой папки в корень `vbs-hub/your-turn-tic-tac-toe`, ветка `main`.

Проверено в двух отдельных браузерных вкладках: создание и вход по ссылке, передача ходов в обе стороны, победа и общий счёт, новый раунд от гостя, отключение и блокировка поля. Подключение между разными физическими сетями отдельно не проверялось.
